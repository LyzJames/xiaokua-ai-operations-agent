# 德国能效咨询：合成技能样例

1. 核对咨询 SKU 和适用市场。
2. 查询经过人工确认的产品规格与政策版本。
3. 只有资料明确包含能源效率等级时才引用该等级。
4. 没有资料时说明需要人工核实，避免自行推断。

原始依据见 [合成证据](references/evidence.md)。

该技能不授予平台写入、退款或广告操作权限。草稿需要人工核对后启用。
