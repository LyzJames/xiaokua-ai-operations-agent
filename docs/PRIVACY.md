# 公开材料与隐私边界

GitHub 当前版本只提交应用源码、运行/部署说明、合成使用样例和测试报告。测试源码、平台验收驱动、私有配置、数据库及原始证据不在当前发布树中。此前提交历史不重写，旧版本仍可恢复；“当前版本移除”不表示从 Git 历史永久删除。

## 不提交的资料

- Key.txt、`.env`、密钥、LWA Refresh Token、平台账户与授权标识。
- `data/`、会话、组织成员、订单/商品/连接/事件的真实资源引用，业务数据库与备份。
- 原始平台响应、模型提示词和正文、飞书事件、未经审查的平台截图。
- 本机 `tests/`、测试入口和验收脚本、测试日志与原始截图目录。

公开 `.env.example` 只含占位项；演示登录信息只服务于绑定回环地址的合成体验模式。它们不能用作试运营凭据。

## 报告与图片

`journeys-acceptance.json` 以字段白名单保留三个案例的步骤、时间、来源、合成金额/库存及布尔验证。不包含商户域名、应用/成员/订单/商品标识、凭据、模型正文或真实买家信息。Amazon 静态样例的姓名/电话/地址在适配器转换时丢弃，不进入公共快照。

本轮图片是同一公开 JSON 在 `journey-evidence.html` 上渲染的**脱敏报告页面原始截图**，页面明确标注该来源。图片未裁切、遮盖或修饰，不冒充平台原始业务界面。README 的工作台示例来自既有离线合成店铺，画面明确标注合成数据。

发布前对每张图片检查画面和嵌入元数据；文本同时检查秘密模式、个人机器路径、非示例联系信息和私有已知值。`screenshot-manifest.json` 记录图片来源及 SHA-256；`public-manifest.json` 记录公开文件哈希，自身不参与哈希清单。扫描只能提供已知范围的证据，不能替代维护者逐次审查。

分类回归报告只保留类别、状态、汇总及运行环境；不公开失败堆栈或测试参数。本机测试代码仍可由测试者保留和执行，但不会随当前源码提交。

## 对使用者的要求

接入自己的店铺时，凭据由自己的部署私密存储，技能导出、审计与模型报告可能含商业信息。不要直接把实际导出上传公开仓库、Issue、PR 或图片。对外演示使用合成买家、无身份信息的客服记录和测试网关。

如发现凭据泄露，先撤销或轮换相关凭据，再按 GitHub 的私密安全反馈渠道联系维护者；不要在公开 Issue 重复粘贴秘密。试运营数据管理与备份准备见 [部署指南](DEPLOYMENT.md)。
