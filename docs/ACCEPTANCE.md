## 本次重新验证（2026-10-12，Asia/Shanghai）

当前优化版的业务闭环、权限与安全、Agent 分析、记忆与技能、恢复与发布五类回归均通过。测试同时运行 SQLite 和一次性真实 PostgreSQL，前端构建及合成流程验收通过。分类结果见 [test-categories.json](test-categories.json)。

本轮三个真实案例均从买家前台 Test Payment Gateway 结账开始，平台回读为 web 来源和测试收款。之后真实飞书 SDK 事件触发同步与模型分析，工作台提案由不同成员通过真实卡片批准或拒绝，Worker 写入测试资源并回读，最后核对通知、业务快照和审计导出。三个案例分别完成履约与物流更正、全额测试退款与取消补库存、咨询技能复用与商品说明改进后履约；均通过统一结案校验。

公开图片分为真实案例脱敏报告、只含虚拟输入的实际测试结账，以及已标注的离线合成基线。原始账号、资源标识、完整事件、订单和平台截图留在私有目录。没有真实交易资金、采购或物流标签支出；使用自己的模型 API 会按服务商规则计费。

离线证据可由测试、演示入口与 CSV 复现；真实案例需自己的平台权限、测试店铺、模型和浏览器操作。模型结构与证据范围通过不代表答案质量基准。两种成员身份由同一测试操作者控制，验证权限分离，不代表独立自然人协作。组织/连接初始化走应用 API，没有声称浏览器 OAuth 安装全流程已验收。

此前优化阶段的 [连接检查](live-readonly-check.json) 与 [strict 检查](live-strict-model-check.json) 只验证身份/只读访问及合成模型输入。这组探针不发送消息或业务写入，范围比本轮完整案例小。
