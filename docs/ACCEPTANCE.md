# 验收范围与证据类型

当前版本 0.4.1 的主要证据是三笔全新买家前台测试订单，每个案例从一开始就纳入 Shopify 和 Amazon 多店调度，贯穿真实模型、独立审批、库存台账、平台回读和审计。

- [测试报告与完整流程图片](TEST_REPORT.md)：案例 A 履约/物流更正、B 退款/取消、C 技能复用/商品改进/异常履约。
- [自己的账号如何复现](USER_JOURNEYS.md)：前台结账、两店指令与最终状态检查。
- [逐阶段脱敏记录](journeys-acceptance.json)：来源、时间、安全读数和验证断言。
- [本机分类回归](test-categories.json)：业务、权限安全、Agent、记忆技能、恢复发布。

Shopify 使用实际开发店铺和测试网关；Amazon Orders 是官方静态样例，FBA/MCF 使用托管动态沙箱；模型为真实 API。两种审批身份由同一操作者控制。商家仓初始数量为合成开账，非实际仓库盘点。案例 C 已完成商家仓后备履约，但 FBA 库存核实项仍保留。

报告页面截图明确标为脱敏报告，不是平台原始界面。原始账号、资源标识、响应、截图和测试代码留在测试者私有本机。GitHub 当前版本只包含应用、文档和报告；CI 负责生产构建，不重跑这些账号业务。

未完成 Amazon 生产账户、真实资金/采购、其他平台、真实物流、公网分发、容量或合规认证的验收。真实试运营准备见 [DEPLOYMENT.md](DEPLOYMENT.md)，Amazon 资格及当前能力见 [平台实现说明](../backend/production/platforms/README.md)。
